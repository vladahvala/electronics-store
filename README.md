# Electronics Store

Інтернет-магазин побутової техніки для обліку товарів, клієнтів і замовлень.

## Основні можливості

### Товари

Система підтримує зберігання та керування такими даними про товари:

- **Назва товару**
- **Категорія:** телевізори, DVD-програвачі, холодильники, пральні машини тощо.
- **Ціна**
- **Виробник:** назва компанії, країна та місто виробництва або складання (необов'язково).
- **Технічні характеристики**, залежно від категорії:
  - **Телевізори:** габарити, діагональ екрана, роздільна здатність, формат екрана, кількість каналів тощо.
  - **Холодильники:** габарити, колір, кількість і розташування камер, мінімальна температура в морозильній камері, об'єм камер, енергоспоживання тощо.
  - **Пральні машини:** габарити, максимальне завантаження, швидкість віджимання, енергоспоживання тощо.
- **Наявність на складі та кількість одиниць товару.**

### Клієнти

Для кожного клієнта зберігаються:

- ПІБ;
- контактна інформація: адреса, номер телефону та електронна пошта;
- історія оформлених замовлень.

### Замовлення

Кожне замовлення містить:

- дату й час оформлення;
- інформацію про клієнта;
- перелік товарів та їхню кількість;
- загальну вартість;
- умови доставки: адресу та бажаний час доставки, визначені клієнтом;
- поточний статус замовлення:
  - **В обробці**;
  - **Зібране**;
  - **Доставлене**.

## Підтримувані операції

### Робота з товарами

- Отримання списку товарів із фільтрацією за категорією, виробником і технічними характеристиками.
- Отримання інформації про характеристики, наявність і ціну конкретного товару.
- Додавання та видалення товарів.
- Перегляд і редагування інформації про товари.

### Робота з клієнтами

- Додавання та видалення клієнтів.
- Перегляд інформації про клієнтів.
- Редагування даних клієнтів.
- Перегляд історії замовлень клієнта.

### Робота із замовленнями

- Оформлення замовлень із зазначенням товарів, їхньої кількості та умов доставки.
- Перевірка поточного статусу замовлення.

## Призначення проєкту

Проєкт призначений для автоматизації обліку побутової техніки, керування інформацією про клієнтів і підтримки основних операцій із замовленнями в інтернет-магазині.
